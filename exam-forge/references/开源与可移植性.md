# 开源与可移植性

> 给你自己用时，这一节基本可以跳过。**准备把技能包发给别人、或提交到公共仓库时，必须读。**

## 技能包没有安装器

程序能靠代码保证行为，技能包只有一段文字 + 一次 AI 判断。所以它在你的环境里跑得通，**不代表在别人环境里跑得通**——而失败方式往往不是报错，是**悄悄跑偏**。

已知的失效点，按危害排序：

| 失效点 | 后果 | 应对 |
|---|---|---|
| **不会"先提大纲等确认"**（弱模型直接跳过） | 用户拿到一份没确认过配比的卷子，还以为是对的 | 把「必须先提大纲」写成硬约束，不要写成建议 |
| **不认识 `references/`、`specs/`** | 附属文件白写 | 在需要时写清完整相对路径（用正斜杠，Windows 也认） |
| **图省事跳过输入自检** | 编出一份看着像样的假卷子 | 输入自检必须最先执行 |
| **四个模式串味** | 出卷时聊起刷题规则、刷题时开始解释知识点 | 动手前先读 `SKILL.md` 的模式契约 |
| **不同 AI 工具的相对路径解析不同** | 找不到附属文件 | 引用附属文件时给出相对于本技能目录的完整路径 |
| **环境只读** | 错题本、待确认清单、规格全部丢失，用户以为存了 | 见 `SKILL.md` 的前置条件：写盘失败必须当场告知 |

**根本病根**：技能包只能**请求**行为，不能**强制**行为。所以规则要写得让"偷懒"比"照做"更麻烦。

## 编号命名空间

**完整定义在 `SKILL.md` 的「编号命名空间」一节**（`卷次-序号` / `卷次-W序号` / `卷次-变序号` / `直出-YYYYMMDD-NN` / `外部卷-序号`）。
这里只说明**为什么需要它**：稿件来源不止一处时，裸题号会串号——落盘、排序、历史回溯、「列出从未错过的题目」都会错。
（只在一门课、一份卷子自用时感觉不到，所以这一条只在多卷多来源时才重要。）

## 开源前必做（防个人数据泄漏）

本技能会写入三类**个人数据**，绝不能进公共仓库：

| 路径 | 内容 |
|---|---|
| `specs/科目名.md` | 你的课程清单、你的老师、你的偏好 |
| `output/科目/错题本.md` | **你的真实错题、真实薄弱章节** |
| `output/科目/待确认清单.md` | 你跟 AI 争论过的答案、你手上的依据来源 |

公开仓库里应当**只保留空模板 `specs/_模板.md`**，不保留任何一份填好的规格。分发前检查：

- [ ] `specs/` 只有 `_模板.md`，没有填好的规格
- [ ] `.gitignore` 已包含 `specs/*.md`（`_模板.md` 除外）与 `output/`
- [ ] 没有把自己的错题记录、真实试卷、老师姓名提交进去
- [ ] 示例文档用**纯文本**跑通记录，**不用截图**（否则没有视觉模型的用户看到的是白纸）
- [ ] README 里有免责声明与许可证说明
