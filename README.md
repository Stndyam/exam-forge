# 考试锻造器 · exam-forge

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)
[![Skill: exam-forge](https://img.shields.io/badge/skill-exam--forge-blue.svg)](exam-forge/SKILL.md)

> **v0.1.0 — 能用，但没被验证过。**
> 流程是完整的、跑得通的；但**没有任何人拿它真跑过一门课**。这是一个能用起来的起点，不是一个经过检验的方法。作者是学生，不是教育研究者。

**一个装在 AI 里的备考工具。** 把你手里那点残缺资料（老师的 PPT、课本片段、同类教材、临时口述的重点）变成一套「知道会考什么」的模拟卷，然后陪你逐题刷到错题全对。

**期末突击能用，当阶段性复习计划也能用。** 它自带剂量调节——错得越多，下一轮加权加题越多。所以短到考前一天、长到一整个学期，用的是**同一套机制**，只是轮数不同。

> 但要说清楚：它是**引擎，不是计划表**。不排日程、不管进度、不提醒你该学哪一章。

要造的不是「练习题」，是**可预期性**：

> 焦虑的燃料是未知——「老师会考什么」。这个工具不预测考题，它把**未知的考场替换成已知的考场**：卷子只能从你自己的资料里长出来，所以你必须知道它会考什么，因为它只能考那些。

---

## 它不承诺什么

**不承诺押中题，不承诺让你考高分。** 它承诺的是开考那一刻你**不再慌**——因为范围是你自己的资料划出来的，题是你做过一遍的。

这个定位决定了工具的取舍：**可预期性 > 命中率**。一份「我们知道它只能考这些」的卷子，比一份「押中率很高但你不知道它靠不靠得住」的卷子更有价值。

## 需要什么

| 需要 | 说明 |
|---|---|
| **一个能读文件的 AI** | 见下方「支持哪些平台」 |
| **可写的工作目录** | 技能的记忆全落在文件上（错题本、待确认清单、科目规格）。**目录不可写时它仍能出卷和刷题，但会退化成没有记忆的一次性用法**——它会如实告诉你 |
| **你的课程资料** | PPT / 课本 / 同类教材 / 历年题 / 你自己记得的重点。**残缺也没关系，这是常态** |
| **视觉能力（可选）** | 如果 PPT 是图片型而你的 AI 读不到图像，它会**如实告诉你读不到**，并给三条退路。**它不会靠文件名猜内容** |
| **成本** | 一次性出完一门课的卷子，通常在 **1-3 元**量级。钱不是这个工具的约束 |

### 支持哪些平台

**已在 [DeepSeek Harness](https://github.com/deepseek-ai) (DSH) 上实测可用。**

其他支持 `SKILL.md` 技能机制的 AI 工具（Claude Code、Codex、OpenCode 等）**理论上兼容、但未经验证**。

**为什么只写一个**：这个项目自己的铁律是"不知道就说不知道"。没有实测过的平台就标未验证——**如果你在别的工具上试了，欢迎回来告诉我们结果**（见 [CONTRIBUTING.md](CONTRIBUTING.md)）。

**一处已知约束**：科目规格写在技能目录内的 `specs/` 下，所以**技能目录本身也需要可写**。如果某个工具把技能装在只读位置，规格会存不下来（错题本不受影响，它写在项目根目录的 `output/` 下）。

## 怎么用

装好之后正常说话就行：

```
帮我出《军事理论》的期末模拟卷，资料我发给你
用我的规则辅导我，科目：创新创业教程，第 3 章
帮我建一门新课的规格：大学生心理健康
```

不用背命令。技能会在你说「出卷 / 出题 / 刷题 / 辅导我」时自动接上。

## 五条核心原则

**1. 不知道就说不知道（证据等级）**

每道题的答案和解析都带一个等级标记：

| 等级 | 含义 |
|:---:|---|
| **A** | 你给的资料里有原文，直接引用（会标出处） |
| **B** | 从你给的资料直接推导 |
| **C** | 来自公开题库或同类教材（会标来源） |
| **D** | **模型生成，资料里没有依据** —— 解析开头会写「⚠️建议考前确认」 |

**它绝不伪造引用。** 资料里没有，它就说没有。理由很简单：一份伪造引用的解析，比一份没有解析的卷子危险得多——**它会让你带着错误的确定感进考场**。

**2. 先提大纲，等你确认，才出卷**

题型、题量、分值它先提一版给你看，你砍掉不想要的题型它才动手。**砍题型是你的停止线，它不会劝你加回来。**

**3. 不制造新焦虑**

不写「必考」「高频」「押中率」——它无法知道这些，写出来只会制造新的焦虑。也不报进度、不催你刷完。**一份没刷完的卷子，不该变成新的失败证据。**

**4. 刷题时只当考官，不当老师**

逐题出、你答完给答案和解析、然后立刻出下一题。**不加引导语、不暗示你选的对不对、不做总结、不鼓励。**

两个特殊指令：

- `pass` —— 跳过这题，**计为错题**，给答案后继续
- `luna` —— 「不确定的蒙题」，**无论对错都进错题库**，给答案后继续

**5. 规格只在你说的时候才建**

每门课可以存一份「规格」（卷型大纲、你的偏好、它踩过的坑）。**它不会主动建议你建规格、不会自动写盘。** 只在出完卷后问一行「要存成规格吗」，你说不要就不再提。

原因：**一个会在你耳边说「要不要顺便建个规格呀」的工具，对本来就焦虑的人是纯噪声。**

## 一个省钱的实际用法：出卷付费，刷题免费

**展开来说，这是个两段式的用法**——它也是这个工具被设计成"出卷与刷题解耦"的现实原因。

| 阶段 | 用什么跑 | 成本 |
|---|---|---|
| **① 出卷**（一次） | 把资料喂给能用的模型，产出**试卷 + 答案解析**，存成文本 | 一次性，通常 1-3 元/门课 |
| **② 刷题 + 错题循环**（反复） | **拿试卷和答案解析，去找免费模型循环** | **0** |

具体怎么做：

1. 用这个技能出好卷子，**把试卷本体和答案解析复制成纯文本**（本来就是 markdown，直接复制）
2. 打开任意免费模型，**把规则正本 [`exam-paper/references/rules-verbatim.md`](exam-forge/references/rules-verbatim.md) 加试卷加解析一起丢给它**
3. 它就会照着规则陪你逐题刷、判卷、跑错题循环
4. **刷完让它把错题列出来给你**——按规则正本的格式列
5. 把那份错题列表拿回来存进 `output/科目/错题本.md`

**为什么第 5 步重要**：错题本是下一轮出卷的加权依据（错得多的知识点自动加题）。**你把它带回来，下一份卷子就自动往你薄弱的地方加题**——而这一整轮刷题，一分钱没花。

### 这条路走得通，是因为三件事被提前定死了

- **试卷和解析是纯文本**，随手复制粘贴就行，不依赖任何特定工具
- **规则正本是独立文件**，可以整份带走，不绑在技能里
- **题号是完整编号**（`A卷-12` / `A卷-W3`），换个模型也不会串号

### 但有几件事得说清楚

- **别的模型没有你的资料。** 它能陪你刷这份卷子，但**出不了新题**——想出新题得回到有资料的这一边
- **解析质量决定它判得准不准。** 解析里标了证据等级，**D 级的内容（模型生成、资料里没依据）它一样判不准**，别指望换个模型就变可靠
- **上下文会丢。** 免费模型多聊几轮就忘了前面的题，所以"让它列出错题"这一步**必须做**，别偷懒指望它记得

## 为什么这么设计

见 [`docs/设计说明.md`](docs/设计说明.md) —— 讲**设计取向**而不是使用方法：

- 它为什么不押题、只要"可预期性"
- 三根轴（知识界限 / 知识点不变 / 出卷刷题解耦）各自约束了什么
- **可验证性**：为什么"内部完成的步骤必须留一个看得见的产物"
- **诚实即防线**：输入自检、证据等级 A/B/C/D、写盘失败必须说
- 两个反直觉的设计：不给建议只报事实、允许不完美地结束

## 一种可能的用法：把它当学习工具

见 [`docs/学习用法设想.md`](docs/学习用法设想.md) —— **这是设想，不是承诺，也没有被系统验证过。**

思路是：不做临考突击，而是**以章节为单位**一章一章过（13 章的书就分 13 批），每批走完整的「出卷 → 刷 → 错题循环 → 换皮重做」。走完一轮，这本书就不再是"完全看不懂的一本书"。

它治的其实是**启动成本**——看不懂一本书时缺的不是深度，是"每个词都陌生"带来的开不了头。刷题先给一层眼熟和一堆概念，让你从"什么都不懂"变成"有东西可以下手"，**之后再去读那本书，是在有基础的状态下读**。

同一套机制既服务考前一天，也服务一整个学期——**只是刷的轮数不同**。

文档里也写了**已知的两个真问题**：需要大量时间才成立；熟悉感和真掌握在体感上很难区分。

## 自己做一份规格

出卷前它会先查 `specs\<科目名>.md`，有就照你的规矩来，没有就用默认大纲。

一个新科目**不用**先写规格 —— 直接让它出卷，出完它问你「要存成规格吗」，你说要就会生成。第一门课跑完，后面这门课一句话就能开工。

模板见 [`exam-forge/specs/_模板.md`](exam-forge/specs/_模板.md)。里面最值钱的一节是**「纠正历史」**——每次你纠正它一条规则就记一行，下次直接生效。**这才是「不用每次重新教 AI」的载体。**

## 已知限制

**说清楚比藏着好。**

1. **它替代不了理解，也替代不了上课。** 它给你的是熟悉感和启动成本，不是掌握。刷题产生的「我很熟」和「我真的会了」在体感上很难区分——**别把状态当终点**。
2. **技能包没有安装器。** 它只是一段文字加一次 AI 判断。换个弱模型，可能会出现「跳过确认直接出卷」「不去读 specs」这类**悄悄跑偏**，而不是报错。
3. **资料越残，它越只能靠公开题库兜底。** 而公共课虽是全国统一考点体系，**每个学校老师出题并不一样**——它会如实告诉你哪些部分是猜的。
4. **主观题不自动判分。** 简答/论述它给参考答案和采分点，算不算错由你自己说。

## 关于开源

这个仓库里**只有工具，没有别人的个人数据**。

`specs/` 里除模板外的内容、以及刷题产生的错题记录，都是**使用者自己的**，已在 `.gitignore` 中排除。**你 fork 之后写的东西不会进上游，也不该提交上去**——那里面有你的真实错题和薄弱章节。

如果你想贡献一份「通用课型参考」，欢迎，但请注意：**不要把某个具体学校、具体老师的偏好当成普遍标准。** 这个工具的立场是「格式是待确认的假设，不是标准答案」。

### 有话想说？开 issue 就行

**Issues 是开着的**——不需要贡献指南，不需要先 fork，不需要打招呼。

**特别欢迎这几类反馈**（它们对你可能没用，但对下一个人有用）：

- **跑偏报告**：换个模型之后技能不按规矩来了（比如跳过确认直接出卷、不去读 `specs/`）。这是这个项目最需要的信息
- **文档错误**：写错的、自相矛盾的、看不懂的段落
- **实测反馈**：真的拿它跑过一门课之后的感受——**哪怕结论是"这东西没用"，也是有价值的信息**
- **你写的规格示例**：如果某门课的规格你调得很好，分享出来能让别人少走弯路

**但要如实说：作者不承诺回复，也不承诺修。** 这个项目是业余产出，没有维护承诺（见下方「维护与支持」）。

**门开着，但不保证有人在。** 你提了，作者会看；能不能处理，取决于他当时有没有空、以及这事是不是真的重要。**这不是敷衍，是不想让一句"欢迎反馈"变成你等不到的承诺。**

**想知道什么反馈最有用**（尤其是"跑偏报告"这一类）→ 见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
