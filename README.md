# 考试锻造器 · exam-forge

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)
[![Skill: exam-forge](https://img.shields.io/badge/skill-exam--forge-blue.svg)](exam-forge/SKILL.md)

> **v0.1.0 — 能用，但没被验证过。** 流程完整、跑得通，但**没有任何人拿它真跑过一门课**。作者是学生，不是教育研究者。

**一个装在 AI 里的备考工具。** 把残缺资料（老师的 PPT、课本片段、同类教材、临时口述的重点）变成一套「知道会考什么」的模拟卷，然后陪你逐题刷到错题全对。

要造的不是「练习题」，是**可预期性**：

> 焦虑的燃料是未知——「老师会考什么」。这个工具不预测考题，它把**未知的考场替换成已知的考场**：卷子只能从你自己的资料里长出来，所以你必须知道它会考什么，因为它只能考那些。

**不承诺押中题，不承诺让你考高分。** 承诺的是开考那一刻你不再慌。

---

## 怎么用

把 `exam-forge/` 整个目录放进 AI 的技能目录，然后正常说话：

```
帮我出《军事理论》的期末模拟卷，资料我发给你
用我的规则辅导我，科目：创新创业教程，第 3 章
帮我建一门新课的规格：大学生心理健康
```

不用背命令。说「出卷 / 出题 / 刷题 / 辅导我」时它会自动接上。

**需要什么**：一个支持技能机制的 AI + **一个可写目录**（记忆全落在文件上，目录不可写时会退化成没有记忆的一次性用法，它**会如实告诉你**）+ 你的课程资料（**残缺是常态，没关系**）。

**支持哪些平台**：**已在 [DeepSeek Harness](https://github.com/deepseek-ai) 上实测可用**。其他支持 `SKILL.md` 的工具（Claude Code、Codex、OpenCode 等）**理论兼容但未验证**——这个项目的铁律是"不知道就说不知道"，没测过就标未验证。

**成本**：作者实测 **15 分钟约 4 元**（高峰更贵）。不是免费工具，但也不是负担。想省钱见下方。

## 五条核心原则

**1. 不知道就说不知道。** 每道题的答案解析都带证据等级 —— **A** 资料原文可引用 / **B** 资料直接推导 / **C** 公开题库或同类教材 / **D** 模型生成、资料里无依据（会标「⚠️建议考前确认」）。**绝不伪造引用**：一份伪造引用的解析，比没有解析的卷子危险得多——它会让你带着错误的确定感进考场。

**2. 先提大纲，等你确认，才出卷。** 题型、题量、分值先给你看一版，你砍掉不想要的它才动手。**砍题型是你的停止线，它不会劝你加回来。**

**3. 不制造新焦虑。** 不写「必考」「高频」「押中率」，不报进度，不催你刷完。**一份没刷完的卷子，不该变成新的失败证据。**

**4. 刷题时只当考官，不当老师。** 逐题出、答完给答案解析、立刻下一题。不加引导语、不暗示你选得对不对、不总结、不鼓励。三个指令随时可用：

| 指令 | 作用 |
|---|---|
| `pass` | 跳过本题，**计为错题** |
| `luna` | 不确定的蒙题，**无论对错都进错题库** |
| `争` | **我不服这个答案**（会记入待确认清单，下一轮出卷时重提） |

**5. 规格只在你说的时候才建。** 每门课可存一份「规格」（卷型大纲、你的偏好、它踩过的坑），**但不会主动建议、不会自动写盘**。只在出完卷后问一行「要存成规格吗」，你说不要就不再提。

## 一个省钱的用法：出卷付费，刷题免费

| 阶段 | 用什么跑 | 成本 |
|---|---|---|
| **出卷**（一次） | 资料喂给能用的模型，产出**试卷 + 答案解析**，存成文本 | 一次性 |
| **刷题 + 错题循环**（反复） | **拿试卷和解析去找免费模型循环** | **0** |

1. 出好卷子，把**试卷和答案解析复制成纯文本**（本来就是 markdown）
2. 免费模型里丢进**规则正本 + 试卷 + 解析**
3. 它照规则陪你逐题刷、判卷、跑错题循环
4. **刷完让它把错题列出来**
5. **把那份错题列表带回来**存进 `output/科目/错题本.md`

**第 5 步是关键**：错题本是下一轮的加权依据（错得多的知识点自动加题）。带回来，下一份卷子就自动往薄弱处倾斜——**而中间那一整轮刷题一分钱没花。**

**这条路走得通，是因为三件事被提前定死**：试卷解析是纯文本（随手可复制）、规则正本是独立文件（可整份带走）、题号是完整编号（换模型也不串号）。

## 目录结构

```
exam-forge/          ← 只需要装这个目录
├─ SKILL.md          ← 入口：路由 + 三根轴 + 前置条件 + 验收清单
├─ references/       ← 按需加载，不做某件事就不用读它
└─ specs/_模板.md     ← 规格模板

docs/ · examples/ · README · CONTRIBUTING · LICENSE   ← 只是资料，不用装
```

**自己做一份规格**：出卷前它会查 `specs/科目名.md`，有就照你的规矩来。新科目**不用**先写规格——直接出卷，出完它问你「要存成规格吗」。模板里最值钱的一节是**「纠正历史」**：每次你纠正它一条规则就记一行，下次直接生效。**这才是「不用每次重新教 AI」的载体。**

## 已知限制

**说清楚比藏着好。**

1. **它替代不了理解，也替代不了上课。** 它给的是熟悉感和启动成本，不是掌握。刷题产生的「我很熟」和「我真的会了」在体感上很难区分——**别把状态当终点**。
2. **技能包没有安装器。** 它只是一段文字加一次 AI 判断。换个弱模型可能出现「跳过确认直接出卷」「不去读 specs」这类**悄悄跑偏**，而不是报错。
3. **资料越残，它越只能靠公开题库兜底**，而每个学校老师出题并不一样——它会如实告诉你哪些部分是猜的。
4. **主观题不自动判分。** 简答、论述给参考答案和采分点，算不算错由你自己说。
5. **一处已知约束**：科目规格写在技能目录内的 `specs/` 下，所以技能目录本身也需可写（错题本不受影响，它在项目根目录的 `output/` 下）。
